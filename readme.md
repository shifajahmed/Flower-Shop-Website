
# Flower Shop Website

A modern and responsive flower shop website designed to showcase beautiful flowers and provide a simple, user-friendly shopping experience.

## 🌐 Live Demo

🔗 **Live Website:** [https://shifajahmed.github.io/Flower-Shop-Website/]

## ✨ Features

* 🌷 Modern and clean user interface
* 📱 Fully responsive design
* 🛍️ Flower product showcase
* 🔍 Easy and simple navigation
* 💐 Attractive flower collection
* 📦 Product details and shopping sections
* ⚡ Fast and smooth user experience

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Tailwind CSS

## 📁 Project Structure

```text
flower-shop-website/
├── assets/
├── images/
├── index.html
└── style.css
```

## 🎯 Purpose

This project was built to practice frontend development skills and create a clean, responsive e-commerce-style website for a flower shop.
